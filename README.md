# Бот подписки на приватный чат (оплата криптой через @CryptoBot)

Что делает бот:
- в личке пользователю выставляет счёт на подписку ($ в фиате, платит он в USDT/TON/BTC на выбор — курс на момент оплаты);
- после оплаты сам продлевает подписку и выдаёт одноразовую пригласительную ссылку в приватный канал;
- за 3 дня до окончания подписки сам напоминает и выставляет новый счёт на продление;
- если не продлили — через грейс-период (по умолчанию 2 дня) сам убирает из канала;
- есть админ-команды `/stats`, `/grant`, `/trial`, `/find`, `/setprice`, `/list`.

## Админ-команды (доступны только тем, чей id указан в `ADMIN_IDS`)

| Команда | Что делает |
|---|---|
| `/stats` | сводка: активные/просроченные подписки, оплаты и выручка за месяц |
| `/grant <telegram_id> <дней>` | вручную выдать/продлить доступ (перенос текущих участников, бонусы) — не помечается как триал |
| `/trial <telegram_id> <дней>` | выдать бесплатный пробный доступ: сразу шлёт человеку инвайт-ссылку и помечает его как триального — напоминание перед окончанием придёт с предложением оформить подписку (а не "продлить") |
| `/setprice <telegram_id> <сумма>` | персональная цена подписки для конкретного человека (скидка); подействует на следующий выставленный счёт. `/setprice <telegram_id> default` — вернуть стандартную цену |
| `/find <telegram_id>` | статус одного человека: подписка, цена, дата окончания |
| `/list` (или `/export`) | выгружает всю базу подписчиков CSV-файлом прямо в чат — открывается в Excel/Numbers/Google Таблицах |

## 1. Создать бота в Telegram

1. Написать [@BotFather](https://t.me/BotFather) → `/newbot` → получить `BOT_TOKEN`.
2. Запомнить username бота без `@` (пригодится для `BOT_USERNAME`).
3. У @BotFather включить приватность или нет — не важно, боту не нужно читать все сообщения в группах.

## 2. Создать приложение в @CryptoBot

1. Открыть [@CryptoBot](https://t.me/CryptoBot) (для теста без реальных денег — [@CryptoTestnetBot](https://t.me/CryptoTestnetBot)).
2. `Crypto Pay` → `My Apps` → `Create App`.
3. Скопировать токен приложения → это `CRYPTO_PAY_TOKEN`.
4. Там же, в настройках приложения → `Webhooks` → включить и указать URL:
   `https://<твой-домен-на-railway>.up.railway.app/cryptobot-webhook`
   (домен появится после первого деплоя на Railway, см. ниже — вебхук можно донастроить вторым шагом).

## 3. Подготовить канал/чат

1. Сделать канал/группу приватными (без публичной ссылки).
2. Добавить бота туда админом с правами: приглашать пользователей по ссылке, банить/снимать бан участников.
3. Узнать `CHANNEL_ID` — самый простой способ: переслать любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot) или добавить в канал ненадолго [@RawDataBot](https://t.me/RawDataBot). Число будет вида `-1001234567890`.

## 4. Перенести уже существующих 15 платных участников

**Важно сделать до включения авто-кика за просрочку**, иначе бот через пару дней начнёт выгонять тех, кто уже честно платит, но не проходил через бота.

Для каждого такого участника:
1. Узнать его `telegram_id` (переслать его сообщение @userinfobot, либо попросить написать боту `/start` — тогда его можно будет найти по `/find`).
2. Выполнить в боте (от админского аккаунта): `/grant <telegram_id> 30` (или сколько дней у него осталось до следующей оплаты по вашей текущей договорённости).

## 5. Переменные окружения

Скопировать `.env.example` → на Railway задать те же ключи во вкладке **Variables** сервиса (файл `.env` на Railway не нужен, только сами переменные).

Обязательные: `BOT_TOKEN`, `CRYPTO_PAY_TOKEN`, `CHANNEL_ID`, `ADMIN_IDS` (свой telegram_id, через запятую если админов несколько).

## 6. Деплой на Railway

1. Запушить этот код в свой GitHub-репозиторий (пустой репозиторий → `git remote add origin ...` → `git push`).
2. В Railway: New Project → Deploy from GitHub repo → выбрать репозиторий.
3. Добавить **Volume**, смонтировать в `/data` (иначе база подписок будет обнуляться при каждом передеплое) — Settings → Volumes → New Volume, mount path `/data`.
4. Задать переменные окружения (шаг 5).
5. Settings → Networking → Generate Domain — это даст публичный URL для вебхука CryptoBot (шаг 2.4).
6. Деплой запустится автоматически.

## 7. Проверка

1. Написать своему боту `/start` — должен прийти счёт.
2. Оплатить тестовую сумму (или через @CryptoTestnetBot).
3. Убедиться, что пришло сообщение "Оплата получена" и пригласительная ссылка.
4. `/stats` от админа должен показать 1 активную подписку.

## Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | точка входа: polling + вебхук-сервер + планировщик |
| `config.py` | все настройки из переменных окружения |
| `db.py` | SQLite-хранилище пользователей и инвойсов |
| `cryptopay.py` | обёртка над Crypto Pay API |
| `payment_logic.py` | обработка успешной оплаты (общая для вебхука и поллинга) |
| `handlers.py` | команды пользователя `/start`, `/pay`, `/status` |
| `admin.py` | команды админа `/stats`, `/grant`, `/find` |
| `scheduler_jobs.py` | ежедневные напоминания и кик за просрочку |
